<h2 id="overview">Overview</h2>

Configured and deployed an Odoo ERP system on Microsoft Azure using Azure Kubernetes Service (AKS), covering virtual machine selection and setup, database configuration, system maintenance, and monitoring.

<h2 id="contribution">My contribution & project context</h2>

My contributions focused on deploying the ERP system and configuring the infrastructure needed to support its ongoing operation.

- Selected a suitable Azure virtual machine based on workload requirements and cost.
- Configured database sizing to balance capacity, resource utilisation, and operating costs.
- Set up monitoring using Prometheus and Grafana to track system health and resource usage.
- Performed system maintenance to support ongoing operation.

**Technologies:** Odoo, Microsoft Azure, AKS, Prometheus, Grafana.

<h2 id="technical">Technical approach</h2>

The deployment work covered VM setup and database configuration alongside the Odoo ERP system on Azure. VM selection and database sizing were guided by the balance between workload requirements, resource utilisation, and operating costs.

Prometheus and Grafana provided monitoring of system health and resource usage to support ongoing operation and maintenance.
